
# Propuesta: Dashboard Web PcShield Store - JRM

## Por qué (Objetivo)

Necesitamos una interfaz web rápida, visual y segura para que el equipo de soporte técnico de PcShield Store - JRM consulte las incidencias y los pedidos procesados en `datos_tickets.json`, filtre los tickets por urgencia, cambie sus estados y registre nuevas incidencias con protección automática de datos personales (RGPD).

## Qué se construye (Alcance)

Un Dashboard SPA (Single Page Application) en `index.html` y `app.js`, utilizando HTML5, TailwindCSS y JavaScript Vanilla, con persistencia de los datos mediante `localStorage`.
